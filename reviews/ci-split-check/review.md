The `COCKPIT_NO_ANDROID=1` skip is unchanged, and so is the final message (`${*:+ ...}` adds nothing when there are no arguments). `.taskcheck` is still `sh scripts/check.sh`.
- **POSIX sh.**
  - `for part in "$@"` and `${*:-...}` / `${*:+...}` are safe under `set -u`: POSIX exempts `$@`/`$*`, and the `:-`/`:+` forms work anyway.
  - The `case " $PARTS " in *" $1 "*` match is exact per word, so `serve` does not match `server`.
  - Calling `selected` inside `if` is exempt from `set -e`.
  - Unknown or empty parts are rejected with exit 2 before anything runs. Repeated parts run once.

I cannot see GitHub branch-protection required checks from here. If one is configured with the old name, a human must rename it.
